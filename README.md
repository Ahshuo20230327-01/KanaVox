# KanaVox - 五十音學習工作台

專為消除「假名記憶盲點」與「發音條件反射訓練」設計的 Windows 原生桌面工作台（WPF / .NET Framework 4.8）。

> **📌 專案狀態**：本專案為作者自用工具，功能已滿足個人學習需求，**後續無維護、功能追加或錯誤修復計畫**，以現狀（As-Is）開源釋出。

---

## ✨ 核心功能
* **五十音動態矩陣**：支援遮罩翻牌、隨機打亂位置、源流漢字提示（涵蓋清音、濁/半濁音、拗音）。
* **行速閃卡練習（Row Blitz）**：自訂練習行、直接鍵入羅馬拼音即時判定。
* **易混淆假名雙色疊影**：針對 シ/ツ、ソ/ン、ぬ/め 等容易混淆的假名進行原點雙色疊合。
* **盲聽測驗**：智慧干擾選項，支援純鍵盤操作作答。
* **視窗記憶**：具備多螢幕防呆校正，自動記錄位置且不飄出邊界。

---

## 📥 下載與使用
1. 前往 [Releases](https://github.com/Ahshuo20230327-01/KanaVox/releases) 下載最新的 `KanaVox-v1.0.0-win-x64.zip`。
2. 解壓縮後直接執行 `KanaVox.exe` 即可（免安裝）。
3. **系統需求**：Windows 10 / 11 (64-bit)。系統多數已內建 .NET Framework 4.8。

---

## 🔊 音訊說明
為遵守版權規範，本發行包**不夾帶任何預錄音檔**：
* **預設語音**：若點擊無聲音，請至 Windows「設定」>「時間與語言」>「語音」安裝微軟官方日文語音包（Haruka / Ayumi）。
* **離線音檔（選用）**：若需完全 0 延遲播放，可自行執行隨附之 Python 腳本 `generate_audio.py` 生成 WAV 檔並放置於 `./Audio` 資料夾。
