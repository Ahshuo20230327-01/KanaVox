## 📖 專案簡介

**KanaVox** 是一套以 C# / WPF 開發的 Windows 日語五十音練習工具。

不同於單純瀏覽靜態字卡，KanaVox 針對初學者常見的學習瓶頸——「依賴表格相對位置猜讀音」、「易混淆字形（如 シ/ツ、ソ/ン、ぬ/め）」以及「缺乏鍵盤打字肌肉記憶」，提供視覺比對、打字輸入與聽覺的即時反射訓練。

本專案採用**零外部套件相依**的輕量化架構，維持開箱即用的體驗。為了符合開源授權規範，GitHub 發行版本不隨附具版權疑慮的預錄語音檔，預設直接呼叫 Windows 內建語音引擎；同時隨附本機音訊產生指令碼，並支援介接本機 Ollama 執行語言模型輔助學習。

## ✨ 功能特色

### 1. 🔤 五十音動態記憶矩陣
* **遮罩翻牌模式**：隱藏按鈕下方的讀音標記，先在腦中回想發音，點擊播放音訊時同步揭曉答案。
* **隨機打亂順序**：打亂 46 格假名位置並自動收合空格，打破對表格行列座標的慣性記憶。
* **漢字字源提示**：於假名右上角標記源流漢字（例如 `あ←安`、`ア←阿`、`ぬ←奴`），輔助筆畫聯想。
* **完整音系收錄**：涵蓋清音（46 音）、濁音 / 半濁音（25 音）、拗音（33 音），支援平假名、片假名與羅馬拼音即時切換。

### 2. ⚡ 行速閃卡練習（Row Blitz）
* **自訂練習範圍**：可勾選指定行（例如專攻 `な行` 與 `ま行`），集中反覆練習。
* **直接鍵盤鍵入**：程式自動擷取鍵盤英文字母，不需手動切換輸入法即可直接鍵入羅馬拼音（完整相容 `shi/si`、`chi/ti`、`tsu/tu`、`fu/hu` 等常用拼法）。
* **即時前綴比對**：輸入正確讀音的最後一個字母時，程式立即發音並跳至下一題；若輸入錯誤則顯示字源提示並重置輸入欄位。
* **螢幕虛擬鍵盤**：提供滑鼠點擊式小鍵盤，支援「A-Z 字母順序」與「QWERTY 排列」，自動將日語未使用的字母（`L, Q, V, X`）反灰停用。

### 3. ⚠️ 易混淆字形雙色疊影
* **原地雙色疊合**：針對容易辨識錯誤的假名組合（`シ vs ツ`、`ソ vs ン`、`ぬ vs め`、`る vs ろ`、`ね vs れ vs わ` 等），以天藍與珊瑚紅兩色在同一座標重疊繪製。
* **比對關鍵筆畫**：直接觀察起筆角度、出頭與收尾繞圈差異，釐清字形結構與筆勢特徵。

### 4. 🎧 盲聽四選一測驗
* **鍵盤快捷操作**：支援 `Enter` 進入下一題、`空白鍵` 重播發音、數字鍵 `1` ~ `4` 作答。
* **智慧誘答機制**：優先挑選外型相近、母音相同或同行的假名作為干擾選項，強化辨音與字形辨識敏銳度。

### 5. 📚 情境例句與發音練習
* **振假名（Furigana）標註**：例句均附漢字假名標註、羅馬拼音與繁體中文翻譯。
* **假名即時連動**：點選左側假名矩陣，右側自動篩選出包含該假名的實用生活例句。
* **跟讀輔助**：支援單句循環播放、慢速朗讀，以及將含假名標註的句子複製至剪貼簿。

### 6. 🤖 本機 Ollama AI 助教（選用功能）
* **預設純淨模式**：發行版本預設關閉 AI 介面，未安裝 Ollama 亦不影響主程式各項功能。
* **支援本機 LLM**：勾選啟用後自動連線本機 Ollama 服務（支援 `qwen2.5` 等模型），可即時生成練習例句、記憶口訣，或將日文句子轉換為振假名格式。

### 7. 🖥️ 視窗狀態記憶
* 自動儲存關閉前的視窗座標與尺寸。具備多螢幕邊界檢查機制，若移除外接螢幕或變更顯示設定，會自動將視窗校正回有效顯示範圍，避免視窗移出畫面邊界。

## 🔊 音訊架構與設定說明

為了符合微軟服務合約與語音授權規範，**KanaVox 的 GitHub 發行版本不隨附任何預錄音檔**。

### 音訊運作邏輯
1. **本機快取優先**：若程式目錄下的 `Audio/` 資料夾內存在對應的 `.wav` 音檔，系統會載入記憶體進行即時播放。
2. **後備機制（系統 TTS）**：若未放置離線音檔，程式會自動切換為 Windows 內建的 **SAPI 日語語音引擎** 即時朗讀。

---

### ⚙️ 前置需求：安裝 Windows 日語語音套件

若 Windows 系統未安裝日語語音引擎（Haruka / Ayumi），在無離線音檔的情況下點擊將無聲音。請依照以下步驟新增：

1. 開啟 KanaVox，點擊右下角 **「🔊 離線音檔說明」**，於快顯視窗點選 **「⚙️ 安裝 Windows 日文語音」**（或手動開啟 Windows `設定` $\rightarrow$ `時間與語言` $\rightarrow$ `語音`）。
2. 在「管理語音」區塊點擊 **「新增語音」**。
3. 搜尋 **「日文」** 或 **「日本語」**，勾選並安裝。
4. 安裝完成後重新啟動 KanaVox，狀態列顯示 `TTS: Microsoft Haruka Desktop` 即代表設定完成。

---

### 🛠️ 自行生成離線音檔（選用）

專案根目錄隨附音檔生成指令碼 `generate_audio.py`，可透過微軟神經網路語音引擎產生離線音訊：

#### 操作步驟：
1. 確認本機已安裝 Python 3.8+ 與 ffmpeg。
2. 開啟終端機（PowerShell 或命令提示字元 CMD），安裝 `edge-tts` 套件：
   ```bash
   pip install edge-tts
   ```
3. 執行生成指令碼：
   ```bash
   python generate_audio.py
   ```
4. 指令碼執行完畢後，會自動在專案目錄下建立 `Audio/` 資料夾並填入所有假名音檔，KanaVox 啟動時即會自動優先讀取該目錄。

## 💻 系統需求

- **作業系統**：Windows 10 / Windows 11（64-bit）
- **執行環境**：.NET Framework 4.8 或更新版本
- **（選用）Ollama**：若需使用 AI 助教功能，需預先安裝 [Ollama](https://ollama.com/) 並下載對應模型（例如 `ollama run qwen2.5:7b`）。

## 🔨 開發與建置

若您希望自行編譯專案原始碼：

1. 複製專案儲存庫：
   ```bash
   git clone https://github.com/your-username/KanaVox.git
   cd KanaVox
   ```
2. 使用 **Visual Studio 2022** 開啟方案檔 `KanaVox.sln`。
3. 確認工作負載已勾選 **.NET 桌面開發**（含 .NET Framework 4.8 開發相依項目）。
4. 設定組態為 `Release | Any CPU` 或 `Release | x64`，執行「建置方案」（`Ctrl + Shift + B`）。
5. 編譯完成之執行檔位於 `bin/Release/` 目錄下。
